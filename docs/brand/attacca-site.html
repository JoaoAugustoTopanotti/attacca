The relay

Built like a repo, played like a song

attacca borrows the parts of Git that matter for music: propose a change, keep the history, credit everyone.

01 — Start

Someone lays the first track

A new transcription needs only one line to begin. The rest of the instruments start empty — on purpose.

Blackbird — new tab
+ Guitar  by @rafa
02 — Continue

You add a track as a proposal

Pick an empty or rough part, transcribe it, and open a proposal. Nothing you build overwrites someone else’s work.

on Master of Puppets  by @emma
03 — Merge

It’s merged, credit stays

Maintainers accept the proposal, the track fills in, and your name is kept in the contributors — for good.
